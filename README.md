# คู่มือการอัปเดตและใช้งานระบบบันทึกสัตว์น้ำ หว้ากอ (Waghor AquaLog / WG_Fishmanager)

เอกสารฉบับนี้สรุปสิ่งที่ได้แก้ไขเพิ่มเติมในเวอร์ชันล่าสุด พร้อมขั้นตอนที่ต้องทำต่อบน **Google Apps Script** เพื่อให้เว็บแอปออนไลน์เชื่อมกับ Google Sheets และใช้งานฟีเจอร์ทั้งหมดได้อย่างสมบูรณ์

---

## 1. สรุปสิ่งที่อัปเดตในเวอร์ชันนี้ (3 รายการ)

1. **แก้บั๊กหน้าบันทึกด่วนเมื่อบันทึกแล้วกดเปลี่ยนตู้ปลาทันที**
   - แก้ไขปัญหาเมื่อบันทึกซากในตู้เดิมแล้วกดเลือกตู้ใหม่ แต่รายชื่อปลาในช่องเลือกยังคงค้างของตู้ก่อนหน้าจนต้องกด F5
   - ระบบจะล้างช่องค้นหาชื่อปลา รีเฟรชรายการ `<select>` ของตู้ใหม่ทันที แสดงป้ายยืนยัน `ตู้ <รหัส> • พบ X ชนิด` พร้อมไฮไลต์สั้นๆ และหากกดตัวกรอง `น้ำจืด / น้ำเค็ม / ตู้ของฉัน` จนตู้เดิมไม่อยู่ในรายการ ระบบจะสลับไปยังตู้แรกที่ตรงเงื่อนไขให้อัตโนมัติ
   - เพิ่มการตัดช่องว่างหัวท้ายของรหัสตู้/ชนิดสัตว์น้ำ (`trim`) และป้องกันการซิงก์พื้นหลังทับลำดับข้อมูล

2. **เพิ่มฟีเจอร์ "เพิ่มชนิดสัตว์น้ำใหม่ (นอกบัญชีกลาง)" เฉพาะในเมนูตั้งค่า**
   - เปิดให้เพิ่มได้เฉพาะในหน้า **ตั้งค่า (ไอคอนฟันเฟืองมุมขวาบน)** เพื่อป้องกันเจ้าหน้าที่เพิ่มชื่อซ้ำโดยไม่ตั้งใจ (ไม่มีปุ่มบนหน้าบันทึกด่วน)
   - กรอกได้ทั้ง: ชื่อภาษาไทย, ประเภทน้ำ (`น้ำจืด` / `น้ำเค็ม`), หน่วยคิดราคา (`บาท / ตัว` หรือ `บาท / กิโลกรัม`), ราคากลางอ้างอิง และตัวเลือก **บังคับชั่งน้ำหนักตอนตาย** (`Species_Rules`)
   - มีระบบตรวจชื่อซ้ำแบบเรียลไทม์และแจ้งเตือนชื่อใกล้เคียง
   - ระบบจะออกรหัสแยกขึ้นต้นด้วย `SPX001`, `SPX002`, ... บันทึกลงแท็บ `Master_Species` (และ `Species_Rules` หากเข้าเงื่อนไขปลาใหญ่/คิดราคาต่อ กก.) และจะ **รักษารายการ `SPX*` ไว้ไม่ให้ถูกลบ** เมื่อมีการซิงก์จากชีตกลาง (`syncCentralSpecies()`) ในอนาคต

3. **เพิ่มแท็บใหม่ "สรุปการตาย" ประจำเดือน + แผนภูมิ + ปุ่มพิมพ์**
   - เพิ่มแท็บ **สรุปการตาย** ในแถบเมนูหลัก (ทั้งบนคอมพิวเตอร์และแถบเมนูล่าง 6 ปุ่มบนมือถือ)
   - แสดงตารางรายชื่อสัตว์น้ำที่ตายในเดือนที่เลือก พร้อมคอลัมน์: **ที่ | ชื่อชนิดสัตว์น้ำ | ตู้ที่ตาย | จำนวน (ตัว) | มูลค่า (บาท)** และสรุปท้ายตารางว่าเดือนนั้นตายทั้งหมด **กี่ชนิด / จากกี่ตู้ / กี่ตัว / มูลค่ากี่บาท**
   - รองรับตัวกรอง `ทั้งหมด / น้ำจืด / น้ำเค็ม`, ช่องค้นหาชื่อปลาหรือรหัสตู้, การเรียงลำดับ, ปุ่ม **คัดลอกตาราง** (วางใน Excel/Word ได้ทันที), ปุ่ม **ส่งออก CSV**, และปุ่ม **พิมพ์สรุปการตาย**
   - มีแผนภูมิเสริม 2 กราฟ: สัดส่วนน้ำจืด/น้ำเค็ม + 10 อันดับชนิดสัตว์น้ำที่ตายมากที่สุด และ 10 อันดับตู้ที่ตายมากที่สุด

## 2. สิ่งที่คุณต้องทำต่อ (อัปเดตโค้ดขึ้น Google Apps Script)

> หมายเหตุ: หากเปิดไฟล์ `index.html` บนคอมพิวเตอร์อย่างเดียว ข้อมูลจะยังไม่อัปเดตไปที่เว็บแอปออนไลน์บน Google Apps Script ต้องนำโค้ดทั้ง 2 ไฟล์ไปวางทับใน Apps Script และกด Deploy เวอร์ชันใหม่ตามขั้นตอนนี้ครับ

1. **เปิดฐานข้อมูล Google Sheets**
   - เปิดไฟล์ Google Sheets: `ระบบบันทึกสัตว์น้ำ_หว้ากอ_Database`
   - ไปที่เมนูด้านบน **ส่วนขยาย (Extensions) → Apps Script**

2. **อัปเดตไฟล์ฝั่งเซิร์ฟเวอร์ (`Code.gs`)**
   - ในหน้าต่าง Apps Script คลิกเลือกไฟล์ **`Code.gs`**
   - กด `Ctrl + A` แล้วลบโค้ดเดิมทั้งหมดออก
   - เปิดไฟล์ **`code (1).text`** จากโฟลเดอร์ `WG_Fishmanager` คัดลอกโค้ดทั้งหมดมาวางแทนใน `Code.gs`
   - กดบันทึก (`Ctrl + S`)

3. **อัปเดตไฟล์หน้าเว็บ (`index.html`)**
   - คลิกเลือกไฟล์ **`index.html`** ใน Apps Script
   - กด `Ctrl + A` แล้วลบโค้ดเดิมทั้งหมดออก
   - เปิดไฟล์ **`index.html`** จากโฟลเดอร์ `WG_Fishmanager` คัดลอกโค้ดทั้งหมดมาวางแทน
   - กดบันทึก (`Ctrl + S`)

4. **Deploy เป็นเวอร์ชันใหม่ (เพื่อใช้ลิงก์เดิมต่อได้ทันที)**
   - กดปุ่ม **ทำให้ใช้งานได้ (Deploy) → จัดการการทำให้ใช้งานได้ (Manage deployments)**
   - กดไอคอนรูป **ดินสอ (แก้ไข / Edit)** ที่รายการ Web App ปัจจุบัน
   - ช่อง **เวอร์ชัน (Version)** ให้เลือกเป็น **เวอร์ชันใหม่ (New version)**
   - กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
   - *(วิธีนี้จะทำให้ลิงก์ Web App เดิมและ QR Code เดิมอัปเดตเป็นเวอร์ชันใหม่ทันทีโดยไม่ต้องแก้ URL)*

5. **ตรวจสอบแท็บใน Google Sheets**
   - ตรวจสอบว่าในไฟล์ Google Sheets มีแท็บ **`Master_Species`** และ **`Species_Rules`** อยู่ครบตามชื่อเดิม (หากเพิ่มสัตว์น้ำนอกบัญชีกลางที่ต้องชั่งน้ำหนักตอนตาย ระบบจะบันทึกลงทั้ง 2 แท็บให้อัตโนมัติ)

---

## 3. วิธีทดสอบสั้นๆ หลัง Deploy เสร็จ

1. เปิดเว็บแอปจากลิงก์เดิม (แนะนำกด `Ctrl + Shift + R` เพื่อล้างแคชเบราว์เซอร์ 1 ครั้ง)
2. **ทดสอบข้อ 1:** หน้า **บันทึกด่วน** → ลองบันทึกซากตู้ A เสร็จแล้วกดเลือกตู้ B ทันที รายชื่อปลาต้องเปลี่ยนเป็นของตู้ B ทันทีโดยไม่ต้องกดรีเฟรช
3. **ทดสอบข้อ 2:** กดไอคอน **ตั้งค่า (ฟันเฟือง)** มุมขวาบน → เลื่อนลงไปที่ **"เพิ่มชนิดสัตว์น้ำใหม่ (นอกบัญชีกลาง)"** → ลองพิมพ์ชื่อที่มีอยู่แล้วเพื่อตรวจระบบกันซ้ำ หรือลองเพิ่มชนิดใหม่แล้วตรวจสอบในแท็บ `Master_Species`
4. **ทดสอบข้อ 3:** เปิดแท็บ **สรุปการตาย** → เลือกเดือนที่มีข้อมูล → ตรวจสอบตาราง กราฟ ตัวกรอง ปุ่มคัดลอกตาราง และปุ่ม **พิมพ์สรุปการตาย**
